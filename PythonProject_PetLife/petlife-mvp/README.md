# PetLife MVP

PetLife — демо AI-экосистемы для владельцев питомцев: безопасная прогулка по погоде, анализ фото и заявка на ранний доступ.

## Как запустить (localhost)

Не открывайте `index.html` двойным щелчком. Запустите сервер:

1. Дважды нажмите `start.bat`
2. Браузер сам откроет [http://127.0.0.1:8765/](http://127.0.0.1:8765/)

Или в терминале из папки `petlife-mvp`:

```bat
py -3 server.py
```

Остановка сервера: `Ctrl+C` в окне терминала.

## Что работает сразу, без ключей

- Лендинг, навигация, адаптив, счётчик миссии.
- Погода и температура асфальта (Open-Meteo, ключ не нужен).
- Анализ фото: если нет ключа OpenRouter, срабатывает локальный разбор изображения.
- Форма раннего доступа: заявки сохраняются в `data/signups.json`.

## Необязательные ключи

Ключи в `js/config.js` нужны только чтобы анализ фото шёл через внешнюю vision-модель.

- OpenRouter: [openrouter.ai](https://openrouter.ai) → `OPENROUTER_API_KEY`
- Поле `OPENROUTER_MODEL` можно сменить на другую vision-модель с `:free`

OpenWeather больше не обязателен: погода идёт через Open-Meteo.

## Технологии

HTML, CSS, JavaScript и стандартная библиотека Python. Без React, без сборщиков.
